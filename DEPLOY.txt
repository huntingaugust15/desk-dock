Desk Dock — GitHub Pages 部署說明

此版本為純靜態 HTML / CSS / JavaScript，不需要 npm、伺服器或 ChatGPT 登入。
預設：NVDA、VOO；Arsenal（全部賽事：英超、歐聯及盃賽等）；F1 賽程及倒數。

部署方法（從分支發佈）
1. 建立或選擇 GitHub repository。GitHub Free 請使用公開 repository。
2. 解壓縮後，把資料夾內所有檔案上載到 repository 根目錄；index.html 必須在根目錄，不要再包一層資料夾。
3. 開啟 repository 的 Settings > Pages。Source 選 Deploy from a branch，Branch 選 main，資料夾選 /(root)，按 Save。若預設分支不是 main，選實際上載檔案的分支。
4. 等待 Pages 部署完成，開啟 Settings > Pages 顯示的網站網址。

一般專案網址：https://你的帳號.github.io/repository名稱/

iPhone：用 Safari 開啟網站 > 分享 > 加入主畫面；按右上角 ☼ 嘗試保持亮屏。

股票格同時顯示 NVDA 和 VOO，不用手動切換。股票詳情直接內嵌每隻股票的走勢圖，使用 1日／1月／3月／1年／5年按鈕切換，無需 hover 或跳到外部網站。足球詳情可在網站內開啟每場比賽，查看兩隊正選、後備、陣式、換人、入球／紅黃牌、主客隊統計及近五場戰績。開啟中的比賽資料每分鐘嘗試更新；未公布陣容及未提供的數據會顯示空資料提示，賽前球隊本季統計不會當成當場統計。F1 詳情提供頁內賽程、車手積分、車隊積分、排位賽 Q1／Q2／Q3 及正賽成績；可選擇本季賽站，沒有對外跳轉連結。足球詳情已移除介紹及操作說明。按 ⚙ 可修改自選報價及足球偏好。
時間使用 Asia/Hong_Kong，每秒自動更新（含秒數）。報價由 TradingView 持續自動推送延遲資料；網絡恢復及長時間離開後返回頁面會按需要重新連接，無需手動更新。股票報價由 TradingView 提供，可能延遲；足球使用 ESPN Arsenal 跨賽事賽程及賽果資料，首頁按時間顯示最近一場，詳情列出來源已公布的本季賽程及賽果；盃賽抽籤及晉級後的比賽會隨來源公布加入。足球使用 ESPN 公開資料；F1 使用 Jolpica F1 公開 API。來源連線失敗會顯示提示或已儲存資料。第三方資料服務的跨來源設定、可用性及顯示權限可能改變。
偏好設定只保存在當前網站、當前瀏覽器的 localStorage；從舊網站轉到 GitHub Pages 後，會使用這份程式的預設設定，不會自動帶過舊網址的設定。

網站程式沒有 ChatGPT 驗證功能。先前的登入畫面由 Sites 私人託管層提供，此套件不含該託管層，也不含 .openai 設定、帳戶憑證或 Git metadata。

GitHub 官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

F1 首頁格包含下一站的賽道輪廓縮圖，依 Circuit ID 自動選擇。SVG 存放 assets/circuits/，資產來源及授權見該資料夾的 SOURCE.txt。

F1 積分及成績按需從 Jolpica F1 載入，依賽季、資料類型及賽站分開快取；詳情開啟後會隨原有 F1 更新週期重新檢查。未公布成績、更新失敗及已存資料會顯示簡短狀態。

F1 詳情新增衝刺排位賽 SQ1／SQ2／SQ3（OpenF1 歷史成績）及衝刺賽名次／時間／圈數／積分（Jolpica SprintResults），均在頁內顯示。衝刺分頁只列出本季衝刺週末，賽站選擇與一般排位／正賽分開保存。OpenF1 場次會以賽季及賽程日期核對；沒有陣列分段圈速的資料不會推算 SQ 分段。
足球首頁格已固定標題／狀態列及賽事所需高度，避免較矮螢幕時內容重疊；必要時頁面可垂直捲動。

F1 詳情的車手／車隊積分及各項成績顯示車手頭像和車隊 logo。圖片來源見 assets/F1-MEDIA.txt；缺圖時保留姓名縮寫。足球首頁最近一場未完賽賽事旁顯示逐秒倒數；尚未確認時間、延期、取消及已到開賽時間會顯示相應狀態，不會推斷即場開賽。

足球詳情的正選及後備名單加入球員頭像，按 ESPN 球員 ID 配對照片，缺圖時顯示姓名縮寫。照片 ID 表按需載入，資料來源見 assets/FOOTBALL-MEDIA.txt。足球與 F1 倒數共用字級、字體、字重、橙色及窄畫面縮放設定。

足球首頁只顯示一場：即場賽事優先，其次為最近一場已公布的後續賽事；沒有後續賽事時顯示最近賽果。完整賽程及賽果仍可在詳情查看。

足球首頁單場賽事採用 40px 隊徽、14px 隊名及 12px 比賽時間；隊徽置於隊名上方，放大後仍保留完整名稱和倒數間距。

F1 首頁格放大賽道輪廓框至 112×88px、賽站名稱至 28px、正賽時間至 13px；較窄手機使用 104×84px／26px／12px。倒數維持與足球相同的字級和橙色。

新增五項：F1 下一節倒數、香港時間自訂夜間模式、美股開收市倒數、30 分鐘內賽事色框、資料過期提示及自動重連。
交易日曆：2026–2028，含美國夏令時間、假日及提早收市；2028 年後會提示更新，不猜測日曆。
來源：https://www.nyse.com/trade/hours-calendars 及 https://www.nasdaq.com/holiday-trading-hours 。
F1 進行中按預定時段估算，不是即場訊號；股票跨來源嵌入頁不能核實價格最新時間。

足球新增正選公布提示與球場陣式圖。首頁在取得 Arsenal 完整且標明 starter 的 11 人名單後顯示提示，點擊直接開啟比賽陣容。比賽前兩小時及進行中每分鐘檢查，兩至六小時每五分鐘，其餘即將舉行賽事每十五分鐘檢查；只在頁面可見及連線時讀取，並與詳情共用快取和請求。
陣式圖以來源的 formation 與 position 欄位排列，保留球員頭像及球衣號碼；缺乏完整、可辨別站位時保留正選名單。名單與數據可展開查看，後備名單不變。

新增對賽分頁：合併 ESPN head-to-head series 與已載入賽程，核對兩隊、完場狀態、日期及比分，顯示所選比賽前最近五次交鋒；主客場及十二碼另列。
新增賽道資料卡：點擊首頁或 F1 詳情的賽道圖，可選擇本季賽道，查看 2026 官方核對的長度、彎道數、正賽圈數及 Jolpica 最近五次歷屆冠軍。規格來源見 assets/CIRCUIT-DATA-SOURCES.txt。
設定新增大字／標準／緊湊模式，儲存於目前裝置。標準保留既有大小，大字可上下滑動；跨來源內嵌股價圖表字級保持由供應商控制。

新增球員表現分頁：只使用所選比賽 rosters 的個人統計，列出實際提供的射門、射正、關鍵傳球、入球、助攻、撲救等指標，支援球隊篩選與並列排名；缺失資料不作零處理，未上陣後備不列榜。
防劇透預設關閉，可在頂部眼睛按鈕或設定啟用；每場比分、本場數據、往績、F1 各節成績／本輪積分和賽道歷屆冠軍須各自揭曉。隱藏資料不寫入畫面或可讀標籤；正選姓名及賽程保留。開關設定儲存在本裝置，揭曉狀態只留在本次頁面，重新開啟再次隱藏。

科技新聞：首頁第四格，科技新報與 iThome RSS 標題。GitHub Actions news.yml 約每 30 分鐘收集，前端每 5 分鐘讀取 main 分支的 raw assets/news.json；本地快取及 Pages 內的 JSON 作備援。新聞沒有全文轉載或 AI 摘要，閱讀原文會另開來源網站。公開 repository 排程可能因 GitHub 負載延遲，或長期無活動而停用；頁面兩小時未取得新資料會標示可能過期，可在 Actions 重新啟用或手動執行。來源： https://technews.tw/tn-rss/ 、 https://www.ithome.com.tw/rss

返回操作 navigation-1：
同一頁面的 History API 記錄首頁、詳情和比賽／賽道層級。瀏覽器返回或對話框取消會退上一層；頂部上一層按鈕同樣使用 history.back。X／點擊背景會回到首頁，首頁繼續返回可正常離開。前進、重新載入、BFCache 返回會還原分頁、賽站、圖表時段和新聞來源；瀏覽紀錄只保存選項，不保存比分或防劇透揭曉狀態。設定頁也納入返回層級，前進保留同一頁面尚未儲存的表單內容；重新載入後仍以已儲存偏好為準。實測桌面瀏覽器返回／前進及 390px 手機版面，未在 iPhone 實機測試滑動手勢。
